# 検証状況

- 元となる拒否修正版について、ユーザーから「動くことを確認した」と報告を受けています。全国での生成成功や全図面の目視合格を意味しません。
- 短測線の誤拒否・端点目盛修正は元の検証で5件＋6サブテスト合格。元約304.54m測線のDWG再オープン成功は、元バージョンでの検証結果であり、今回の公開用コピーの再検証とは別です。
- 公開用コピーについて実施する整合性・選択回帰試験・GUI起動確認は、別の `evidence/packaging_checks.json` に記録します。
- 公開用コピーの合成平野サンプルで、新規ネイティブDWG生成・再オープン検査を実施しました。入力・ハッシュ・検査記録は `examples/synthetic_plain/` と `dwg/` に同梱しています。
- ライブ地図からの新規取得と、人間による公開用コピーのDWG目視確認は未実施です。合成入力の成功から格上げしません。
- GitHub ActionsはPython側の試験です。AutoCAD成功や地質学的正解の認定には使いません。

アルファ版は機能・適用範囲に制約があります。ソフトウェアの公開可否、個々の図面の利用可否、地質学的妥当性は別の判断です。
