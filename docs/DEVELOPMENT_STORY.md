# 開発の経緯と設計

## 断面図の作業を、入力から作図までつなぎたい

このプロジェクトは、AutoCAD/Dynamo上で岩相断面図のケバを作成する作業を自動化する取り組みから発展しました。ケバ作成では、ハッチ区画と岩相交点の座標が一致しない場合にも、順序と対応関係を保って作図することに取り組みました。

そこから「断面図を描く補助だけでなく、地域資料を参照した岩相断面を生成し、DWGまでつなげられないか」という方向へ対象が広がりました。これは開発の経緯であり、このアルファ版にケバ作成機能が統合されているという意味ではありません。

## 使う人に複雑な設定を押し付けない

地図で二点を選ぶと測線が決まる、普段使わない設定は折りたたむ、画像・DWG・検査結果は同じGUIから開く。この操作の流れを優先しました。JSONの手入力や複数のバッチ操作を通常手順にはしていません。

## 苦労した点と対応

### 選択できる範囲と、実際に支援できる範囲の違い

距離の円を表示しても、すべての地点で資料が揃うわけではありません。距離上限を500mに絞り、地図の選択制約と生成要求の制約を共通化しました。ただし500m以内は成功保証ではありません。地質区分が混在する地点などは現在も拒否します。

### 正常な短測線を、別目的の試験で拒否してしまう

過去の約304.54mの測線では、地質形状とは別目的の乱数サンプラー回帰試験が測線長に影響され、生成を拒否していました。回帰試験を既定の500m・51測点の参照条件に戻し、測線そのものの検査と分離しました。判定閾値を下げて通したわけではありません。

### 保存後のDWGで文字が衝突する

端点の正確な距離と、その近くの通常目盛が重なる問題がありました。端点表示を保ち、近すぎる中間の数値表示を省く配置に修正しました。生成時だけでなく、AutoCADで保存し直した図面の再オープン検査を重視しています。

### 高度化と、安定して試せる範囲を分ける

岩相の多様性、深部構造、3Dモデルからの断面抽出などは、別の研究開発として進めてきました。しかし機能が存在すること、GUIに接続されていること、生成結果が妥当なことは別です。本版は、確認できた旧二点指定経路を小さなアルファ版として切り出したものです。

## 技術的な流れ

地図A/B → 距離・方位 → 公開地形・地表地質の取得 → 地質区分の判定 → 合成岩相断面 → 接触・面積・作図検査 → ネイティブDWG保存 → 再オープン検査。

岩相境界や層厚には推測が含まれます。滑らかな図や正常なDWGができても、その地下構造が現実と一致した証明にはなりません。拒否を隠さず、観測と推測を区別し、利用者が結果を点検できることを優先しています。

## 今後

まずはアルファ版の導入・二点指定・拒否理由・図面の読みやすさに関するフィードバックを集めます。高度な3D推定や複雑な地質表現は、本版の実績に混ぜず、別途検証したうえで扱います。
