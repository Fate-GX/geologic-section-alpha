# アルファ版の範囲

維持：二点指定、詳細設定、条件保存・読込、生成、PNG/DWG、拒否理由、整合性・凍結基盤・ネイティブ再オープン検査。

除外：Next研究API入力メニュー、Next研究モジュール一式、過去の実行記録・地図キャッシュ・個別試用座標、過去の参考DWG/画像、旧起動ファイル、開発端末の絶対パスを含むビルド中間物。

公開資料の補足として、新規に生成・再オープン検査した合成サンプルを同梱しました。過去の利用者データではありません。

公開用ランチャーと説明資料のみを整理し、Advanced V2の地質生成・閾値・作図コードは元版と同一に保ちます。内部依存がある基盤コードとルールは、GUIに露出しなくても削除しません。

元の凍結基盤計算ツリー（206ファイル）は保持します。テストツリーから端末依存のobj中間JSONを除くため、公開コピーの凍結マニフェストだけは配布対象に合わせて再記録します。元の検証版・凍結版のファイルは変更しません。この包装上の再記録を、元の366ファイル全体のバイト同一性とは主張しません。

`docs/packaging_provenance.json` は維持したファイルのハッシュと包装変更を記録します。
