# 再現サンプル：合成平野断面

**地形・地質区分とも合成のソフトウェア試験です。実際の座標地点の地質を説明する図ではありません。** 地図タイルや外部データを配布せず、同梱入力で計算を再現します。

- 測線：東向き500m、二点の非丸め値は `input.json`
- seed：880100
- エンジン：公開用Alpha 0.1.0、通常のAdvanced V2パイプライン
- 置換するもの：外部資料取得の入力だけ。地質計算・形状検査・契約生成は本体を実行
- 生成PNG：[断面プレビュー](section_preview.png)
- ネイティブDWG：[合成サンプル](../../dwg/synthetic_plain.dwg)
- 再オープン記録：[検査記録](../../dwg/synthetic_plain_reopen_validation.txt)
- [入力・出力のハッシュと確認結果](expected.json)

## 再現方法（開発者向け）

必要な依存ライブラリを導入したPythonで、リポジトリのルートから実行します。

```console
python -B tools/reproduce_sample.py
```

AutoCADがなくても、計算・PNG・DWG作成用契約までを実行し、ポリゴンと地形のハッシュを基準結果と照合します。

Windows + AutoCAD 2027で新規DWGも保存・再オープンする場合：

```console
python -B tools/reproduce_sample.py --native
```

GUI利用者は同梱の画像・DWGを見るだけでも構いません。**通常GUIで同じ二点を地図選択すると実資料を取得するため、この合成入力と同じ結果にはなりません。** このサンプルを実地域の生成成功例として扱わないでください。

## 再現の範囲

同じ入力と依存ライブラリで、ポリゴン・地形座標のハッシュ一致を検査します。DWG全体のバイト一致は、時刻・AutoCAD内部情報の影響があるため要求しません。依存版が変わると浮動小数点値・画像文字描画等が変わる場合があります。公開時の依存版は `evidence/packaging_checks.json` に記録しています。

PNGはプログラム出力をそのまま掲載しています。汎用見出しにDEM/GSJという語が残りますが、今回の実際の入力源は画像下部にも記載された合成試験データです。先頭の説明と入力JSONを優先して解釈してください。

ネイティブ再オープン検査は成功しましたが、人間によるDWGの最終目視確認・地質学的承認ではありません。プレビューはエージェントが確認し、文字の可読性・凡例・枠の収まりを確認しました。平行帯状の単純な生成例であり、高度版の複雑な3D構造を示すものではありません。
